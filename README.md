# DIBI Higher Education Dashboard

The DIBI Higher Education Dashboard is a centralized platform designed to connect academic institutions, faculty, and research capabilities across the Defense Industrial Base.

I am leading the technical initiative to transition the existing platform from Airtable to Microsoft Azure, developing a more scalable, customizable, and secure cloud-based infrastructure.

## Key Objectives

- Migrate existing data from Airtable to Azure.
- Develop an interactive faculty and research directory.
- Improve data accessibility, search, and filtering capabilities.
- Establish a scalable database and web application architecture.

## Tech Stack

- React
- TypeScript
- Bootstrap
- Microsoft Azure
- Airtable

## Project Status

Currently in development, with a focus on frontend development, database architecture, and cloud migration.
